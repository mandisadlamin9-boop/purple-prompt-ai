# Aura Workspace — AI Workplace Productivity Assistant

A premium, responsive web application that helps teams write better emails, turn messy meeting
notes into clear action items, and get instant answers from an AI workplace assistant.
**No registration, sign-in or account is required** — every tool is available immediately.

## Project Overview

Aura Workspace is a SaaS-style AI dashboard built around three everyday workplace jobs: writing,
summarising, and asking. It presents a clean white interface with a purple-only palette, gradient
accents, soft shadows, rounded cards and generous whitespace, and works equally well on desktop
and mobile.

## Features Implemented

- **Smart Email Generator** — describe the message, pick a tone (Formal, Friendly, Persuasive) and
  length, and get a complete professional email with subject line, greeting, body and sign-off.
- **Meeting Notes Summarizer** — paste raw notes or a transcript and receive a structured markdown
  summary with Key Decisions, Action Items (with owners), Deadlines and Open Questions.
- **AI Chatbot Interface** — an interactive workplace assistant with suggested prompts, full
  conversation memory, markdown-rendered answers and typing indicators.
- **Premium dashboard UI** — sidebar navigation (collapsible drawer on mobile), gradient hero,
  tool cards and refined typography (Sora + Plus Jakarta Sans).
- **Editable AI outputs** — every generated result can be edited inline, copied or downloaded.
- **Loading, empty and error states** — skeleton loaders, guiding empty states, and friendly error
  messages with retry (including rate-limit and credit-exhaustion handling).
- **Responsible AI disclaimer** — shown in the sidebar, under every output, and in the footer.
- **Structured AI prompts** — each feature uses a purpose-built system prompt and validated inputs.
- **No authentication** — no login, registration, or user data collection.

## Technologies and Tools Used

- **React 19** + **TypeScript**
- **TanStack Start** (SSR framework) and **TanStack Router** (file-based routing)
- **TanStack Query** for client data management
- **Vite 8** build tooling
- **Tailwind CSS v4** (CSS-first design tokens in `src/styles.css`) + **shadcn/ui** components
- **Vercel AI SDK** (`ai`, `@ai-sdk/openai-compatible`) via the **Lovable AI Gateway**
  (model: `google/gemini-3.7-flash`)
- **Zod** for input validation, **react-markdown** for rendering, **lucide-react** for icons

## Setup Instructions

```bash
# 1. Install dependencies
bun install      # or: npm install

# 2. Provide the AI key (server-side only)
#    Create a .env file:
#    LOVABLE_API_KEY=your_key_here

# 3. Start the dev server
bun run dev      # http://localhost:8080

# 4. Production build
bun run build
```

The AI key is read only inside server functions and is never exposed to the browser.
